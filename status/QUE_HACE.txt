¿QUÉ HACE?
Alias en inglés de /estado. Muestra el estado del árbol de trabajo de Git.

COMANDOS QUE EJECUTA / REEMPLAZA EN SEGUNDO PLANO:
1. git branch --show-current
2. git status -s
3. git status -uno
