================================================================================
SKILL: /sync
================================================================================
¿QUÉ HACE?
Sincroniza bidireccionalmente el proyecto de código actual con su repositorio
remoto en GitHub en 1 solo comando seguro:
1. Asegura y comitea los cambios locales pendientes para no perder nada.
2. Descarga e integra las novedades remotas mediante 'git pull --rebase'.
3. Sube los commits locales limpios a GitHub mediante 'git push'.

COMANDOS QUE EJECUTA / REEMPLAZA EN SEGUNDO PLANO:
1. git status -s
2. git add . && git commit -m "chore: sincronizar cambios locales" (si hay pendientes)
3. git pull --rebase origin <rama-actual>
4. git push origin <rama-actual>

EJEMPLOS DE USO:
- /sync
- /sincronizar
- sincronizar con github
