================================================================================
SKILL: /sincronizar
================================================================================
¿QUÉ HACE?
Alias en español de /sync. Sincroniza bidireccionalmente el proyecto actual
con GitHub en un solo paso:
1. Guarda los cambios locales pendientes con git commit.
2. Descarga cambios remotos con git pull --rebase origin <rama>.
3. Sube los commits locales limpios con git push origin <rama>.

COMANDOS QUE EJECUTA / REEMPLAZA EN SEGUNDO PLANO:
1. git status -s
2. git add . && git commit -m "chore: sincronizar cambios locales" (si aplica)
3. git pull --rebase origin <rama-actual>
4. git push origin <rama-actual>

EJEMPLOS DE USO:
- /sincronizar
- /sync
- sincronizar proyecto
