¿QUÉ HACE?
Muestra una radiografía rápida del estado actual de tu proyecto: en qué rama
estás, qué archivos están modificados o sin guardar, y si estás al día con GitHub.

COMANDOS QUE EJECUTA / REEMPLAZA EN SEGUNDO PLANO:
1. git branch --show-current
   (Muestra la rama actual)
2. git status -s
   (Lista compacta de archivos modificados, agregados o eliminados)
3. git status -uno
   (Verifica si hay commits pendientes por subir a GitHub)

EJEMPLOS DE USO:
- /estado
- como esta el proyecto
