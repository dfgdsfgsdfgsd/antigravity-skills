================================================================================
SKILL: /init
================================================================================
¿QUÉ HACE?
Alias en inglés de /iniciar. Inicializa el repositorio local de Git en el
proyecto actual con su .gitignore y commit inicial.

COMANDOS QUE EJECUTA / REEMPLAZA EN SEGUNDO PLANO:
1. git init -b main
2. Creación inteligente de .gitignore (node_modules, venv, .env, temporales)
3. git add .
4. git commit -m "feat: commit inicial del proyecto"

EJEMPLOS DE USO:
- /init
